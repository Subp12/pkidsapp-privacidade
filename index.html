Sobre o aplicativo

Mundo das Cores é um jogo de pintura para crianças de 3 a 5 anos. Esta versão é gratuita, funciona offline e não contém anúncios, compras, cadastro ou login.

Pinturas e imagens no aparelho

O aplicativo salva localmente o progresso das pinturas. Com ajuda de um adulto, é possível selecionar uma imagem pelo seletor do Android. Somente a imagem escolhida é copiada para a pasta privada do jogo. A cópia pode ser reduzida para até 768 pixels no lado maior. O arquivo original do aparelho não é modificado. O app não solicita acesso geral à galeria, localização, microfone ou câmera.

Envio de dados

O aplicativo não envia imagens, pinturas ou outros dados pessoais para servidores da PkidsApp. Não utiliza anúncios, rastreamento ou serviços de análise de comportamento. Não há contas ou perfis públicos. Os componentes do Flutter usados para escolher imagens e armazenar arquivos e preferências atendem às funções locais descritas nesta política. Se o usuário escolher um provedor de imagens oferecido pelo seletor do Android, as práticas desse serviço são definidas pelo próprio provedor.

Crianças e responsáveis

O jogo foi criado para atividades de pintura infantil. Um adulto deve ajudar na importação e escolher imagens apropriadas. Não há chat, publicação de imagens ou compartilhamento entre usuários pelo aplicativo.

Retenção e exclusão

O progresso fica no aparelho até ser limpo ou até a remoção dos dados do aplicativo. Limpar uma pintura importada restaura sua imagem inicial. A lixeira de Meus desenhos remove apenas a cópia e a pintura dentro do jogo, após confirmação. O arquivo original do celular é mantido. Desinstalar o aplicativo ou limpar seus dados remove os dados locais, incluindo os desenhos importados. Não há conta do jogo ou dados em servidor da PkidsApp para excluir.

Backup do Android

As imagens importadas são excluídas do backup automático configurado pelo aplicativo. As preferências dos desenhos que acompanham o jogo podem participar do backup do Android, conforme as configurações do aparelho. A PkidsApp não tem acesso a esse backup.

Contato e atualizações

Para dúvidas sobre privacidade, entre em contato com pkidsapp@gmail.com. Se novas versões alterarem o tratamento de dados, esta política será atualizada, incluindo a data da mudança.
